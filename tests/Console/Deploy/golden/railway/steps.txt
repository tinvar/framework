# Create the project and link this directory to it.
railway init --name my-app
# The SQLite database, and the files kept beside it, on a volume.
railway volume add --mount-path /var/lib/app/data
# The variables in the open: Railway's edge, inside 100.64.0.0/10, as the proxy (it sends no header of ours, so no TINVAR_TRUSTED_PROXY_SECRET).
railway variables --set 'TINVAR_TRUSTED_PROXIES=100.64.0.0/10'
# The rest: paste each into the service's Variables -- a secret from its file, which never reaches a command line:
#   TINVAR_APP_KEY: pbcopy < '/home/you/.local/state/tinvar/my-app-2cab79174cf3.railway.key'   (xclip -selection clipboard on Linux)
#   TINVAR_PROBE_TOKEN: pbcopy < '/home/you/.local/state/tinvar/my-app-2cab79174cf3.railway.probe-token'   (xclip -selection clipboard on Linux)
# Mail: no provider that sends is named. Once the app sends mail, set TINVAR_MAIL_PROVIDER (smtp, ses, postmark, mailgun, resend or sendgrid) and its variables: production refuses log and array.
railway up
# Then `railway domain`, and set TINVAR_APP_DOMAIN to the https address it gives.
